# Velox Map Locator

A flexible WordPress location directory and map locator plugin by **Velox Plugins**.

Velox Map Locator lets WordPress site owners manage locations once and display them through reusable, configurable locators with synchronized maps, search, filters, business hours, multiple map providers, and privacy-aware loading.

## Features

- Unlimited Locations, Types, Groups, and reusable Locators
- Split Map + List, Map Only, and List Only layouts
- OpenStreetMap, Google Maps, and Custom XYZ map providers
- Search and location filtering
- Near Me distance sorting
- Marker clustering
- Structured business hours and special-date overrides
- Multiple built-in appearance themes
- Responsive and RTL-aware layouts
- Interaction Privacy Mode
- CSV import and export
- Gutenberg block and shortcode support
- Built-in help and documentation
- No Velox telemetry or Velox account requirement

## Requirements

- WordPress 6.6 or later
- PHP 7.4 or later

## Installation

For normal installations, install Velox Map Locator through the WordPress plugin directory or upload the plugin ZIP through:

**Plugins → Add New → Upload Plugin**

After activation, open:

**Velox Map Locator → Help**

for the recommended setup workflow.
