# Security Policy

Velox Plugins takes security issues in Velox Map Locator seriously.

## Supported Versions

Security fixes are applied to the latest stable release of Velox Map Locator. Users should keep the plugin updated to the latest version available from the official WordPress Plugin Directory.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues, pull requests, discussions, or the WordPress.org support forum.**

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository on GitHub.
2. Open **Security**.
3. Open **Advisories**.
4. Choose **Report a vulnerability**.
5. Provide the details needed to reproduce and assess the issue.

Please include, when available:

- affected Velox Map Locator version;
- affected WordPress and PHP versions;
- vulnerability type and potential impact;
- clear reproduction steps;
- proof-of-concept details where appropriate;
- any proposed mitigation or patch;
- whether the issue has been disclosed elsewhere.

Please avoid including real credentials, personal data, or data from systems you do not own or have permission to test.

## Coordinated Disclosure

Please allow reasonable time for Velox Plugins to investigate, prepare a fix, test the fix, and coordinate a release before public disclosure.

Confirmed vulnerabilities may be handled through a private GitHub repository security advisory while a fix is developed.

## Scope

Security reports should relate directly to Velox Map Locator.

General bugs, feature requests, installation questions, and configuration questions should use the normal issue or support channels instead.
